# 개발 가이드 (VS Code)

## 시작
```bash
git clone https://github.com/9rayday/Settlement.git
cd Settlement
code .
```
- 화면 확인: VS Code 확장 **Live Server** → `index.html` 우클릭 → *Open with Live Server*.
  `file://`로 직접 열면 fetch가 막힐 수 있으니 Live Server(또는 `python3 -m http.server`)를 쓴다.
- 배포: `main`에 push 하면 GitHub Pages가 갱신된다. (`js/config.js` 의 GAS 주소는 공개 저장소에 커밋되어 있음)
- 로그인: 구글시트 `관리자` 탭의 아이디/비밀번호.

## 구조
화면은 왼쪽 사이드 메뉴 + 페이지 구성 (주소 `#settle-cust` 처럼 페이지마다 다름, 새로고침해도 유지).

| 메뉴 | 페이지 id | 내용 |
|---|---|---|
| 계약관리 > 전기사용자/발전사업자 > 계약이행현황 | `page-cust-perf` / `page-gen-perf` | 준비 중 |
| 정산관리 > 정산 대시보드 | `page-dash` | 준비 중 |
| 정산관리 > 계약관리 > 전기사용자 / 발전사업자 / 그룹화 | `page-reg-cust` / `page-reg-plant` / `page-reg-group` | 등록·수정 (구글시트 `전기사용자 정보`·`발전소 사업자 정보`), 그룹 = 같은 KPX 신청번호, 그룹 월별 집계 |
| 정산관리 > 정산 > 전기사용자 | `page-settle-cust` | 업로드 카드(정산 구분 + KPX·사용량) + 가정산서/오차정산서 |
| 정산관리 > 정산 > 발전사업자 | `page-settle-gen` | 업로드 카드 + 발전소별 확인/조정 + 정산서 생성 |
| 정산관리 > 정산 > 정산요율관리 > KPX 요율 관리 | `page-rate-kpx` | 월별 KPX 통지 요율 |
| 정산관리 > 정산 > 정산요율관리 > 시간대별 요금제 관리 | `page-rate-tou` | 부하구분 월×시간 표, 공휴일 (앱데이터 `tou`) |

| 경로 | 역할 |
|---|---|
| `index.html` | 사이드 메뉴 + 페이지 마크업. 업로드 카드(`#uploadCard`)는 하나만 두고 정산 페이지로 옮겨 씀 |
| `js/nav.js` | 메뉴/페이지 전환 (`PAGES` 에 페이지 추가) |
| `js/registry.js` | 계약관리 3개 페이지. 시트 행 단위 저장/삭제 (`savePlant`/`saveCustomer`…) |
| `js/billing.js` | 전기사용자 정산(`#tab5`), KPX 요율(`#tab4`), 정산 구분·사용량 처리 |
| `js/tariff.js` | 시간대별 요금제·공휴일 편집 → `Parsers.TARIFF`/`HOLIDAYS` 에 적용 |
| `js/engine.js` | **정산 계산 엔진**. 순수 함수, 브라우저/Node 공용. 월별 요율(`rates`)은 모두 인자로 받음 |
| `js/parsers.js` | KPX xlsx / 고객 15분 `.xls`(실제 HTML) 파서, 부하구분, 공휴일 기본값 |
| `js/store.js` | 요율·청구·이월·요금제 저장 (GAS `앱데이터` 탭 + localStorage 캐시). 키: `rates:YYYYMM`, `bill:YYYYMM:신청번호`(가정산 스냅샷), `carry:익월YYYYMM:신청번호`(오차정산 이월), `tou` |
| `js/invoice.js`, `upload.js`, `exporters/*` | 발전사업자 정산서 (`upload.js` 의 `routeKpxFile` 이 KPX 파일을 발전사업자·전기사용자 양쪽으로 넘김) |
| `gas/Code.gs` | Apps Script 백엔드. **수정 후 시트의 Apps Script에 붙여넣고 "새 버전"으로 재배포** |
| `tests/engine.test.js` | 엔진 검증 (8월 삼성디스플레이 엑셀과 대조) |
| `tools/extract_fixture.py` | 정산 엑셀 → 검증용 fixture.json |

## 검증 (엔진/파서를 고칠 때마다)
```bash
pip install openpyxl
python3 tools/extract_fixture.py "2026-8 삼성디스플레이 ....xlsx" fixture.json   # 실데이터: 커밋 금지
node tests/engine.test.js fixture.json    # 전부 OK 여야 함 (원 단위 일치)
```

## Apps Script 재배포 절차
1. 시트 → 확장 프로그램 → Apps Script → `Code.gs` 전체를 `gas/Code.gs` 내용으로 교체 → 저장
2. (최초 1회) `setupSheets` 실행 → 권한 승인
3. 배포 → 배포 관리 → 연필 → 버전 **새 버전** → 배포 (실행: 나 / 액세스: 모든 사용자). "새 배포"를 만들면 주소가 바뀌니 주의.
4. 사이트 정산관리 > 계약관리에 발전소·전기사용자 목록이 보이고, 저장하면 `발전소 사업자 정보`·`전기사용자 정보` 탭에 반영되면 정상.
   (`발전소 사업자 정보` 에 없는 컬럼 — 담당자, 수수료율, 지역(요금구분), 배전연결, KPX신청번호 — 은 첫 저장 때 맨 끝에 자동 추가된다)

## 월간 운영 순서
0. 정산관리 > 계약관리: 신규 발전소·전기사용자는 최초 1회 등록, [그룹화]에서 발전소를 전기사용자 계약에 묶기. 발전소의 지역(요금구분)·배전연결이 정산에 쓰인다
1. 정산요율관리 > KPX 요율 관리: 이번 달 KPX 통지값 저장. 공휴일은 연초에 [시간대별 요금제 관리]에서 확인
2. **가정산** (매월 초): 정산 > 전기사용자(또는 발전사업자) 위쪽 업로드 카드에서 "가정산" → ① KPX 직접전력거래량 ② 전기사용량 15분 업로드
   - 발전사업자 정산서도 이 파일로 만들어짐 (정산 > 발전사업자)
   - 정산 > 전기사용자: 그룹 선택 → 전월 확정 부가정산금·전월 차액은 저장된 오차정산 값으로 자동 채워짐 → 가정산서 계산 → Excel/PDF → **가정산 기록 저장** (오차정산의 비교 기준)
3. **오차정산** (KPX 확정 후): 업로드 카드에서 "오차정산" → 확정 KPX 파일과 사용량 파일을 다시 업로드 (발전사업자 쪽은 갱신하지 않음)
   - 그룹 선택 → 가정산 값이 자동으로 채워짐 (시스템 밖에서 만든 가정산이면 직접 입력)
   - 확정 부가정산금 총액·과세 비율 입력(자동 분할) → 오차정산 계산 → 차액(과세)이 전력량요금·망이용요금·거래수수료 차이로 채워짐, 차액(비과세)은 직접 입력
   - 오차정산서 Excel/PDF → **오차정산 저장** → `carry:다음달:신청번호` 로 저장되어 다음 달 가정산서에 자동 반영

## 계산 규칙 요약 (engine.js)
- 공급량 = KPX 파일의 재생E공급량(발전소·시간별) 그대로 — 가정산·오차정산 공통 (`matchMonthKpx`). 초과발전량 = 발전량 − 공급량
- 월간균등 정산: 발전량을 월 균등값으로 나눈 뒤 전량 구매 (공급량 = 발전량, 초과발전량 0, `matchMonth(..., { fullBuy: true })`). E-PPA 비용편익과 같은 규칙
- 사용량 파일(15분)은 부하구분별 사용량·부족전력량 표시에만 쓴다. 없거나 빈 시간은 KPX 전기사용량으로 대체
- (참고) `matchMonth` 의 min(사용량, Σ발전량) 방식은 8월 엑셀 검증(`tests/engine.test.js`)용으로 남아 있음
- 오차정산 차액(과세) = (확정 − 가정산)의 전력량요금 + 망이용요금 + 거래수수료 (`trueUpDiff`)
- 전력량요금 = ROUND(공급량×단가) / 거래수수료 = ROUND(공급량×0.1193) / 예상 부가정산금 = ROUND(공급량×단가)
- 망이용요금(발전소별) = TRUNC(ROUND(공급량)×발전측) + TRUNC(ROUND(공급량)×(1−송전손실률)×수요측) [+ 배전연결: ×(1−종합손실률)×3.05]
- 기금 = ROUNDDOWN((전력량요금+망이용요금+수수료+예상부가정산금)×2.7%, −1), 비과세. 청구서 계 = 전월 확정 부가정산금(비과세)+기금+전월 차액(비과세)
- 부가세는 과세 항목(전력량·망이용·수수료·전월 확정 부가정산금·전월 차액(과세))에만 10%
- 부하구분: 일요일·공휴일=경부하, 토요일 최대부하→중간부하, 나머지는 월별 시간대 표
